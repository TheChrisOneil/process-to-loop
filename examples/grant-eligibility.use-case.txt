We run a small community grants program and somebody has to screen the applications before the
review panel sees them. We receive about 140 applications per cycle, four cycles a year. Each
application has an organization name, a requested amount, a project description of up to two
pages, a budget, and a set of attachments.

Two program staff do the screening. They check that the organization is a registered nonprofit
in good standing, that the requested amount falls inside the program's range, that the project
period starts after the award date, that the budget arithmetic is correct, and that the
organization has not already received an award in the last twelve months.

Most of what gets rejected is mechanical. The budget does not add up. The amount requested is
above our ceiling. The registration lapsed. The project starts before we would have paid. Our
staff say those take as long to open as the ones that matter.

The judgment is whether the project as described actually falls inside our funding scope. The
scope is written in the program guidelines, applicants describe their work in their own
language, and a project can be genuinely worthwhile and still be outside what this program
funds. That decision is made on maybe one application in three.

Requests over 25,000 dollars go to the Program Director before the panel sees them, whatever the
screen concluded. Any application from an organization with a current board member in common
with our own board must be flagged to the Executive Director, and it is never screened out
quietly. Last cycle we advanced an application whose budget double-counted a 9,000 dollar line,
and the panel found it rather than us.

Screening currently takes eleven days and the panel complains that it compresses their time.
